# HOFEM development dockerized

## About

Configure a machine with all the tools and dependencies ready to compile and develop HOFEM software.

HOFEM is a software devoloped by GREMA research group that solve electromagnetic problems using High Order Finite Elements.

## Tools installed

- Intel compilers (with MKL and Intel MPI libraries)
- Lmod
- Gfortran (with OpenMPI and openmp libraries)
- Compiled libraries:
  - gidpost
  - metis
  - arpack
  - parmetis
  - scotch
  - parpack
  - mumps
